LifeLocker

A secure digital document vault designed for unhoused individuals.

Built by Alaina Bastien, Benevolence Ed-Malik, and J'adore Jn-Charles. The concept is inspired by Cox's track at Hacklanta 2026 - Social Good.

We're also aiming for the two side challenges:
MLH: Best Use of Auth0
MLH: Best Use of Gemini API

Problem:
People experiencing homelessness often lose access to physical documents required for housing, employment, healthcare, and social services.

Solution:
LifeLocker allows users to upload, store, and quickly share important documents with caseworkers. OCR technology extracts information from uploaded documents to streamline intake processes.

Tech Stack:
- React
- Vite
- Tailwind CSS
- Tesseract.js
- Supabase
- Auth0

How to run locally:
npm install
npm run dev
